# Ambient Glass — OpenExam 设计规范

> 环境玻璃。天空渐变底 + 伪玻璃焦点 + 无边框内容排版。
> 改任何界面之前先读这一页。

---

## 一、风格的三层结构

缺任何一层，整体质感就会塌。

### 1. Ambient Gradient — 环境渐变底

整屏一层渐变，加 2–3 个高斯光斑。这是"液态感"的地基：玻璃必须有东西可折射，
底下如果是纯白或纯灰，玻璃就退化成灰卡片。

| | 顶部 | 中段 | 底部 |
|---|---|---|---|
| 浅色 | `#8FC0EA` | `#BFDBF0` | `#EDF3F8` |
| 深色 | `#13294A` | `#141C2C` | `#0E1116` |

光斑：右上暖白高光、左侧品牌蓝、右中墨青，全部 `RadialGradient` 到透明。

实现：`lib/core/ui/ambient.dart` 的 `AmbientBackground`，挂在 `MaterialApp.builder`
上，所有路由自动继承。

### 2. Faux Glass — 伪玻璃焦点

半透明填充 + 白色高光描边 + 大圆角 + 双层柔和投影。

**禁止使用 `BackdropFilter`。** 真实高斯模糊在中端机上会掉帧（早期版本因此卡顿）。
现在用分层渐变伪造折射感，零 GPU 模糊开销。

实现：`lib/core/ui/glass.dart`
- `GlassDecor.panel()` — 中性玻璃面（弹层、做题选项、搜索框）
- `GlassDecor.tinted()` — 带色玻璃（品牌色按钮、选中态）
- `GlassDecor.sheen()` — 左上角高光扫过

**只给需要浮起来的元素用**：首页状态块、做题选项、解析块、底部弹层。
列表行、设置行、页头一律不用。

### 3. Borderless Layout — 无边框排版

内容不套卡片、不加边框，靠留白和发丝线分组。

- 页头：左上角 26px 大标题 + 13px 副标题。**页头永远不是卡片。**
- 分组：11.5px 字重 600 的小标签（`_GroupLabel` / `SectionLabel`）
- 行与行之间：`RowDivider`（发丝线，左右缩进对齐文字）
- 边距：统一 `AppTheme.gutter = 18`

## 二、硬性规则

1. **一行能放下的信息不要拆两行。** 题型名 + 进度条 + 已练/总数 + 百分比，
   全部同一行，各段固定宽度右对齐，数字不跳动。
2. **不要重复的导航。** 顶部 Tab 和下面的列表如果表达同一件事，删掉 Tab。
3. **图标自绘、统一线宽。** 见 `lib/core/ui/stroke_icons.dart`：24×24 网格、
   1.9px 线宽、圆头端点。不混用 Material 默认图标集（除 chevron 这类纯几何符号）。
4. **功能入口卡走 QQ音乐 模式**：纯色块 + 干净排版 + 右下角白色圆形播放键。
   不要渐变叠大水印图标。
5. **颜色只从 token 取。** 换主题 = 换一套 `AppTokens`，不改页面代码。
6. **数字用等宽字形**（`AppTheme.numeric`），避免刷新时跳动。
7. **进度条空槽用墨色 11%**，不要用 `line`——在浅色渐变底上会看不见。

## 三、色彩

品牌色（浅色 `#1668D6` / 深色 `#5C9DFF`）只用于：主按钮、选中态、进度填充、
关键数字。**不要拿它当装饰色铺开。**

五个题型各有专属色，用于图标、进度条、正确率数字：

| 题型 | 浅色 | 深色 |
|---|---|---|
| 言语理解 | `#1E74D8` | `#62A5FF` |
| 数量关系 | `#E08A1E` | `#F0A83F` |
| 判断推理 | `#7A5CD0` | `#9E86F0` |
| 资料分析 | `#109C93` | `#3EC4B8` |
| 常识判断 | `#D9506F` | `#F06A8B` |

语义色：成功 `#15A46E` / 危险 `#E2483D`（深色各自提亮）。

## 四、字号

| 用途 | 字号 | 字重 |
|---|---|---|
| 页面大标题 | 26 | 700 |
| 区块标题 | 16–17 | 600 |
| 行标题 | 15–16 | 600 |
| 题干正文 | 16（可调 0.9–1.3 倍） | 400 |
| 正文 | 14 | 400 |
| 辅助信息 | 12.5 | 400 |
| 分组标签 | 11.5 | 600 |

系统字体缩放钳制在 0.9–1.1 倍（`app.dart`），防止用户开大显示后版面炸裂。
