- 练习记录时间线：按天汇总答题量与正确率，左侧脊线标出达标日，展开当天各组练习可直接进入回看。
- 空状态自绘插画：EmptyArtwork（箱子/星星/放大镜/柱状图/对勾）替换灰色图标，入场带回弹动画，题库、错题、收藏、笔记、纠错、报告、搜索全部换新。
- 单模块限时练：长按题型行弹出「直接练 / 限时练 / 背题」，限时按各模块考场配速给时长（言语 55s、数量 75s、判断 50s、资料 70s、常识 20s 每题）。
- 徽章重做（lib/features/achievements/medal.dart）：金属质感勋章 —— 背后有 45° 色板、深色面盘、七段 SweepGradient 金属边、沿边跑动的高光、内圈细线、左上玻璃高光，图标做成压印（暗影 + 金属提亮）。五个成就组各有自己的外形（圆 / 花瓣 / 盾 / 方钻 / 六边），四个等级各有铜银金铂配色。
- 徽章展台 MedalStage：呼吸光晕、缓慢旋转的光芒扇、两圈反向环绕的星点、勋章上下浮动，解锁时额外一圈冲击波。未解锁的徽章不跑动画。
- 徽章详情改为整页（BadgeDetailPage）：勋章放到 210dp，左右滑动切换徽章，底部窗口式圆点指示，整屏背景跟着当前徽章的等级色渐变，返回是淡入缩放路由。
- 勋章细节加强：面盘刻上同心 guilloche 纹与 36 条放射细线，边框嵌 16 颗铆钉，右下压印目标数字（上万自动缩成「2万」）与深色铭牌上的成就组名。细节只在 120dp 以上渲染。
- 徽章主纹改为专画（lib/features/achievements/badge_glyph.dart）：钢笔尖 / 火焰 / 靶心 / 卷轴 / 山峰 / 皇冠六种实心纹样，按成就组分配，用 evenOdd 挖出内部结构；上金属渐变、下暗影、外描边，做成压印效果。原来直接放大工具栏描边图标，在勋章上是一根细铁丝。
- 勋章排版校准：边框收窄到 6.6%，铆钉缩小，面盘左右分栏 —— 主纹在左，目标数字与成就组铭牌在右。
- 错题本改为概览优先：进来先看「今日复盘」（错过两次以上的排前面，一键开练）、未标错因提醒、按模块的分布条、按错因的 chip、错得最多的卷，点任意一项直接带筛选进列表；需要逐题翻时再切列表模式，列表模式下头部有回概览的入口。依据是粉笔那套复盘方法（错因标签要具体、按考点归档、同类错因连盯几天）和用户反馈里最常见的一条：错题本一打开就是密密麻麻的题，没人愿意复盘。
- 四天专项复习计划（粉笔「同类错因连盯四天」）：错题本概览里长按任一错因或模块即可开计划，卡片显示四格进度与今天该做的那一步。第 1–2 天不计时慢做，第 3 天按 55 秒/题限时加压，第 4 天掺 8 道同类新题混练验证；每天只算一步，做完当天提示明天再来。数据层新增 review_plans 表与 ReviewPlan 模型，随备份导出。
- 题目难度自评与筛选：做完一题在解析下面标「简单 / 一般 / 难」（再点取消），存进新的 difficulty 表并随备份导出。错题本多一条「难度」筛选（我标了难 / 一般 / 简单 / 没标过），练习首页在标过难题后出现「标难的 N 题 ›」入口，一键把最近标难的 30 题拉出来重练。没有服务器统计就没有全站正确率，「这题对我难」本来也只有自己说了算。
- 页面切换动效：全局 PageTransitionsTheme 换成淡入 + 右侧轻推 22dp（旧页往左让 14dp），替掉 Material 默认那种整屏上推，在浅色渐变背景上不再显得笨重。
- 列表入场：新增通用 Reveal（淡入 + 上移 18dp，按序号递增延迟，超过第 6 项不再等），用在错题列表、练习记录、搜索结果、笔记列表。
- 笔记页整理能力：加搜索框（同时搜笔记正文和题干）与题型筛选，行拆成独立的 _NoteRow，「全部回顾」跟着当前筛选走而不是全量。
- 做题时显示本题历史作答：答完（或回看）在解析下面出现一条「N 次做过 · 错过 M 次 · 上次 8/3」，右边并排显示最近 5 次选的选项，对错用绿/红区分。反复错同一道题却毫无察觉，是错题本最常见的失效方式。
- 首页四天计划提醒：练习首页列出进行中的计划和今天该做的那一步，点一下直接跳到错题本 tab（AppShell.jumpTo，避免 push 一个没有底部导航的副本）。
