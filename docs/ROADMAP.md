# OpenExam 手机端 · 优化路线图

按"对考生的实际价值"排序。每完成一项：`flutter analyze` → 真机安装 → commit → 在这里打勾并记下 commit。

## 进行中

- [ ] **错因标记**：答错后可标「粗心 / 知识点不会 / 看错题干 / 时间不够」，错题本按错因筛选，
      统计页显示错因分布（搜到的复盘建议里这是最高频诉求）
- [ ] **每日目标**：设定每天题量目标，首页顶部显示环形完成度，连续达标记入打卡
- [ ] **中断恢复**：练习/模考意外退出后，下次进入提示"继续上次未完成的 N 题"
- [ ] **题目笔记**：每题可写自己的解题笔记，回顾与错题本中一并显示
- [ ] **智能组卷**：按弱项自动配比出题（正确率低的模块占比更高）
- [ ] **题库筛选**：题库页支持按年份区间、省份/国考、是否含图筛选
- [ ] **收藏分组**：收藏支持自定义标签（如"公式""易错"），可按标签练
- [ ] **搜索增强**：搜索历史、按题型过滤搜索结果、结果内高亮全部命中词
- [ ] **数据备份**：导出练习记录 + 收藏 + 笔记为 JSON，可再导入恢复
- [ ] **导入增强**：支持 zip（题目 + 图片），导入前预览与去重报告
- [ ] **首启引导**：第一次打开介绍四个 Tab 与离线特性，顺便让用户设考试日期
- [ ] **性能**：题库长列表改 `ListView.builder`，图片缓存改 LRU 并限制内存
- [ ] **深色校对**：逐屏检查深色下的对比度，尤其图片底板、玻璃描边、禁用态
- [ ] **冒烟测试**：给数据层与关键交互补 widget/unit test，防止改样式改坏逻辑
