## 母题：上岸

考公的人都说「上岸」。这是中文语境里现成的、带情感的意象，别人抄不走。

| 产品概念 | 视觉 |
| --- | --- |
| 备考过程 | 划船渡海 |
| 每日进度 | 今天划了多少桨 |
| 连续天数 | 灯塔亮了几天 |
| 五个题型 | 五座要经过的岛 |
| 考试日 | 岸 |
| 今日完成 | 靠岸插旗 |

## 色板

底 `#F2F8FC` · 卡 `#FFFFFF` · 主字 `#16232E` · 次字 `#7A8B99`
强调 亮黄 `#FFC94A`（按钮、进度、当前项）· 海蓝 `#1B8FD1`（只给可点文字）
亮黄浅底 `#FFF6E0` 上的字用琥珀 `#B8730F` —— 主字太重、次字又飘。
数字用 Outfit，中文 PingFang。

**两个色分工是量出来的**，不是审美偏好：亮黄在白底上做文字对比度约
1.7:1，读不出来；海蓝做大色块又太重。所以黄管"按下去会发生什么"，
蓝管"这行字能点"。题型色只做 3px 色条和小标签，永远不染卡面 ——
否则每开一个题型，同一个"开始"按钮就换一种颜色。

深色是夜航：同一片海关掉光。底色带蓝（`#0C141E` / 卡 `#152230`），
蓝还是可点的字（`#6FB6E8`），黄还是要按的按钮。插画出两套光，
切主题时画面跟着一起暗 —— 白底贴夜景、黑底贴晴天，都是把插画和
底色放进两个光线世界里。

## 间距节奏

顶部留白 36 · 标题组内 5 · 标题组到内容 22
区块之间 30 · 区块标题到内容 11 · 卡内 8–14

区块间距是卡内的两倍多。两个尺度太接近，页面就会摊成一条列表，
再漂亮的组件拼在一起也会觉得诡异。

## 定制组件

母题不能只停在插图里，这四个每天出现几十次的组件都按航海重做：

- **进度条 → 航迹** 虚线是没走的航段，实线带尾流点，船停在当前位置，终点是灯塔
- **勾选 → 救生圈** 圈上四道白色开口是绑绳
- **图文交界 → 水线** 插画没入水里，不是被直线硬切
- **分数环 → 罗盘** 外圈四主四副刻度是度盘

一个 app 里不该有两种"环形分数"的画法：练习结果、申论批改、数据看板
用的是同一个罗盘。同理，首页的今日航线和复习计划页的今日安排是同一个
清单组件 —— 同一份数据在两个页面长得不像同一件事，是最刺眼的割裂。

**卡是实底加软阴影，不是半透明玻璃。** 上一版卡面是白 0.88→0.62 的渐变
加一圈白描边：背景一变卡就跟着变色，白边在浅底上又几乎看不见，剩下的
观感就是一层塑料膜。边界靠阴影，不靠描边。

**按钮一律全圆角、一律动作色。** 混用 pill / 圆角矩形 / 圆形三种，
一屏里就散了。

## 素材

`assets/shore/` 下 51 个，量化后约 1.1 MB。四套风格锁在 `gen_scenes.py`
里，加新的只写一行主体描述即可：

- `STYLE_DAY` 晴天海场景，给浅色主题（520–640px jpg）
- `STYLE_NIGHT` 夜航版，给深色主题，跟日航一一对应
- `STYLE_BADGE` 圆形奖章形制，给成就（320px png，透明底）
- `STYLE_ICON` 立体小图标，给入口和考试类型（320px png，透明底）
- `STYLE_EMPTY` 极简空态插画（320px png，透明底）

透明底要在请求里写 `background: "transparent"`，不能事后抠白 ——
主体本身常常就是白纸，抠白会把它掏空。

规格必须锁死。上一版每张图各生成各的，结果四屏四种画风，
放一起就散了 —— 协调感的唯一来源是「一整套图出自同一个绘者」。

重新生成：

```bash
export OPENEXAM_IMAGE_KEY=sk-...        # 出图服务的 key，别提交
python3 design/gen_scenes.py            # 全部
python3 design/gen_scenes.py day_yanyu --force   # 单张重出
```

## 重新 seed 画布

```bash
B=<design skill 的 base 目录>
node "$B/seed-canvas.mjs" --template "$B/payload.template.html" \
  --out design/openexam-ui.html --title "OpenExam UI" \
  $(for f in design/*.dc.html; do printf -- "--artboard %s " "$f"; done) \
  $(for f in design/art/*; do printf -- "--image %s " "$f"; done) \
  --canvas design/canvas.json
```
